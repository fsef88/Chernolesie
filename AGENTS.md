# Правила работы в этом репозитории

## Проект
«Чёрнолесье — Защитник Заставы», рогалик-выживач для Яндекс Игр.
Ванильный JS + Canvas 2D, движка нет, зависимостей ноль.
src/ — 91 модуль (~12 500 строк), assets/ — 441 файл, docs/, tools/.
Модули НЕ ESM: ни import, ни export. Склеиваются в порядке src/build.manifest.json
в ОДНУ глобальную область и дают dist/chernolesie.html.
base64 в исходниках нет — его подставляет сборка из assets/.

## Команды
node tools/check.mjs — парсинг всех модулей + дубли имён верхнего уровня
npm run build — сборка dist/chernolesie.html, сверка sha с src/build.manifest.json
Сеть не нужна: зависимостей ноль.
Хеш не изменился после правки = правка не применилась.

## Автономность в пределах хода
В одном ответе выполняй поставленную задачу целиком, до готового результата:
все файлы указанной папки, а не первый из них. Разрешений не спрашивай,
о планах не отчитывайся. Если задача — написать скрипт, то напиши, запусти
и покажи вывод в том же ответе. Между сообщениями работу не продолжай.

## Что искать
check.mjs проходит: 91 модуль парсится, 730 имён верхнего уровня, дублей нет.
Синтаксис и дубли закрыты. Ищи то, что парсер не ловит:
- неявные глобалы: объявлено в одном модуле, читается в другом;
- порядок загрузки: let/const читается до объявления (TDZ при инициализации);
- вызов функции раньше определения, если это не hoisted function;
- операторы, потерянные при разрезе монолита;
- рассинхрон data/ и systems/: ключ есть, обработчика нет, и наоборот;
- пути ассетов, отсутствующие в assets/ (сверяй по манифесту);
- утечки: подписки без снятия, пулы без возврата, рост массивов за забег.

## Запрещено
- фиктивные правки ради отчёта или изменения sha;
- выдавать за находки комментарии в коде о прошлых багах (#1 CRITICAL, тест #T5);
- называть строку, которой нет в файле;
- вердикт «структура пуста» без показа содержимого;
- переименовывать файлы и переносить код между модулями: порядок склейки задан
  манифестом, перенос ломает инициализацию;
- трейлинг-комментарий в конце плотной строки. Комментарий — только отдельной
  строкой сверху: в этом коде трейлинг съедает следующий оператор или скобку;
- переформатировать код, о котором не просили.

## Отчётность
Одна строка на чистый модуль, детализация только по находкам.
Каждое исправление дописывай в docs/known-issues.md, в конец, в раздел исправленного.
Статически недоступное (тайминг rAF, 90/120 Гц, реальный DOM и localStorage,
баланс 30-минутного забега) выноси отдельным списком, не угадывай.
