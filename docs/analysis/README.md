## Краткие выводы

### Сильные стороны
- Отличная система синергий (26 штук)
- Глубокая механика эволюций
- Сильная славянская атмосфера
- Хорошая оптимизация памяти (v7.8)
- Качественная документация

### Главные проблемы
1. **В забеге нет проигрыша.** Замер: бот, который стоит на месте и не
   шевелится, доходит до 28:31 на полном здоровье. Разбор — в
   [06-vs-gap-measured.md](./06-vs-gap-measured.md)
2. **Orphan-файл Воина** — 16 кадров не работают
3. Три файла > 430 строк (сложно поддерживать)
4. Глобальное состояние (40+ переменных)

### Приоритетные задачи
1. Дать врагу расти в летальности, а не только в здоровье
2. Сделать контакт с героем достижимым (сейчас зона поражения ×133 по площади
   больше радиуса контакта)
3. Исправить orphan-файл Воина
4. Разбить `fx-layer.js`, `enemy-ai.js`, `props-anomalies.js`

Пункты про juice и полировку карт из документа 4 остаются в силе, но они
усилитель, а не источник: подсвечивать нечего, пока в забеге нет ставок.
