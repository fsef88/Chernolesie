# Чёрнолесье — Защитник Заставы

Славянский рогалик-выживач для Яндекс Игр. Ванильный JS + Canvas 2D, без движка
и без зависимостей.

---

## Быстрый старт

```bash
npm run dev
```

Поднимет локальный сервер на <http://localhost:5173/> с dev-сборкой: стили
подключены отдельными файлами, ассеты берутся с диска, в DevTools видны
исходные модули (через source map).

Собрать то, что уходит на платформу:

```bash
npm run build
```

Результат — `dist/chernolesie.html`: один самодостаточный файл, ровно как раньше.

---

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сборка + локальный сервер |
| `npm run build` | прод-сборка в `dist/chernolesie.html` |
| `npm run build:dev` | только пересобрать dev, без сервера |
| `npm run check` | синтаксис всех модулей + поиск дублей имён |
| `npm run verify` | сверить сборку с эталонным HTML, ничего не записывая |
| `npm run docs` | пересобрать `docs/architecture.md` из карты разделов |
| `npm run split` | **разово**: перерезать монолит заново (уже сделано) |

## Где что лежит

```
src/styles/     CSS по разделам интерфейса          21 файл
src/markup/     разметка HUD и оверлеев              6 файлов
src/game/       игровой код                         91 файл
assets/         webp/jpg/ttf вместо base64         426 файлов
tools/          разбор, сборка, проверки
docs/           документация
dist/           сборки (в git не хранятся)
```

Полная карта с описанием каждого файла — [docs/architecture.md](docs/architecture.md).

Коротко по `src/game/`:

| Папка | Отвечает за |
|---|---|
| `boot/` | вход в приложение, история сборок |
| `core/` | канвас, ввод, игровой цикл, пулы объектов, RNG, настройки |
| `data/` | **цифры и содержимое**: баланс, классы, враги, карты, божества |
| `state/` | изменяемое состояние забега |
| `systems/` | правила: спавн, директор сложности, эволюции, достижения, Порча |
| `entities/` | игрок и ИИ врагов |
| `weapons/` | арсенал, по наборам |
| `render/` | все слои отрисовки |
| `ui/` | экраны, оверлеи, иконография |
| `audio/` | процедурный звук и музыка |
| `world/` | наполнение карты |
| `platform/` | Яндекс Игры: SDK, реклама, лидерборды, облачные сохранения |

**Правишь баланс — иди в `src/game/data/`.** Там числа и никакой логики.

## Как это устроено

Игра писалась одним файлом и **исполняется так же**: разбиение живёт только в
исходниках, а сборка склеивает всё обратно. Поэтому у разбиения нет
runtime-цены и нет риска что-то сломать порядком загрузки.

Гарантия: `npm run build` из нетронутых исходников выдаёт файл, чей SHA-256
совпадает с исходным `chernolesie_v7 (2).html`. Байт в байт. Сверка идёт при
каждой сборке и печатается в консоль.

Два правила, которые из этого следуют:

1. **Порядок разделов значим.** Всё живёт в одном скоупе; часть кода вычисляет
   имена функций прямо при загрузке (например `core/input.js` вешает обработчик
   на `togglePause` из `ui/overlays.js`). Порядок задан в `tools/manifest.mjs`.
2. **Ассеты подставляются по маркерам.** В коде вместо base64 стоит
   `@@A:sprites/Heroes/Warrior_norm/f_01.webp@@`. Заменил файл в `assets/` —
   пересобрал — готово. Перерисовывать спрайт можно в любом редакторе.

## Рабочий цикл

1. Правишь файлы в `src/` или картинки в `assets/`.
2. `npm run check` — синтаксис и дубли имён.
3. `npm run dev` — смотришь в браузере.
4. `npm run build` — получаешь `dist/chernolesie.html`.
5. Его и заливаешь в Яндекс Игры (архивом с единственным файлом внутри).

Известные особенности и подводные камни — [docs/known-issues.md](docs/known-issues.md).

## Структура разделов меняется так

Границы разделов заданы диапазонами строк в `tools/manifest.mjs` — это карта
первичного разреза. После того как разрез сделан, она нужна только для
документации и порядка загрузки: чтобы добавить новый модуль, положи файл в
`src/game/...` и впиши его в нужное место `src/build.manifest.json`.

Перерезать монолит заново (`npm run split`) нужно только если ты вернулся к
работе с оригинальным HTML — эта команда **затирает** `src/` и `assets/`.
