## 1. Общая характеристика проекта

**Чёрнолесье** — это славянский рогалик-выживач в стиле **Vampire Survivors**, созданный для **Яндекс Игр**.

### Ключевые факты
- **Технологии**: Чистый JavaScript + Canvas 2D (никаких движков)
- **Размер**: ~11 МБ (426 изображений + 91 JS-файл)
- **Исходный размер монолита**: 13 555 строк (92% — base64 картинки)
- **Текущий подход**: Модульная структура с последующей сборкой обратно в один HTML

### Философия проекта
> «Игра исполняется так же, как и раньше — в одном общем скоупе. Разбиение нужно только для удобства разработки.»

Это означает:
- Нет `import/export`
- Порядок загрузки модулей **критически важен**
- Часть кода вычисляет имена функций на этапе парсинга

## 4. Главные проблемы и технический долг

### Критические
- **Orphan-файл Воина** (`hero-warrior-v674.orphan.js`) — 16 новых кадров не загружаются
- Глобальное состояние (40+ переменных в `run-state.js`)

### Высокий приоритет
- 3 файла > 430 строк (`fx-layer.js`, `enemy-ai.js`, `props-anomalies.js`)
- Отсутствие тестов
- Сложная логика синергий в одном файле

### Средний приоритет
- Тяжёлый рендер (9 функций `draw*` каждый кадр)
- Много магии с `window.EMB` и маркерами `@@A:...@@`
