## 1. Исправленные проблемы производительности

### 1.1 Spatial Hash (v6.3)
**До**: `Map<string>` + создание 4300 строк/сек  
**После**: Плоский массив `gridArr` + переиспользование

**Эффект**: Значительное снижение GC pressure.

### 1.2 Сетка разделения врагов (v7.8)
**До**: 10 252 ячейки при 20k px пути → **44 мс/сек**  
**После**: Только занятые ячейки + пул `_sepFree`

**Эффект**: Просадки в конце длинного забега устранены.

### 1.3 Аудио (v7.8)
**До**: 10 забегов = 10 живых `BufferSource`  
**После**: Корректная остановка источников

```js
if (dt > 20) partMul = Math.max(0.3, partMul * 0.9);
else if (partMul < partTarget) partMul = Math.min(partTarget, partMul * 1.01 + 0.002);
```

## 5. Система обновления (update loop)

**Файл**: `core/loop.js`

```js
const PHYSICS_DT = 1/60;
let acc = 0;

while (acc >= 1/60 && steps < 5) {
  if (evoPause > 0) { ... continue; }
  update(1/60);
  acc -= 1/60;
  steps++;
}
```

**Хорошо**:
- Фиксированный шаг
- Ограничение 5 шагов за кадр
- Интерполяция (`interpFactor`)

**Риск**:
- При сильной просадке (`steps === 5`) мир начинает "тормозить"
