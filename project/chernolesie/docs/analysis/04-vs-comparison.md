## 2. Что уже сделано на высоком уровне

### 2.1 Система синергий (лучше, чем в VS)
- 26 синергий
- Появляются автоматически при выполнении условий
- Требуют реального билда (минимум 1–2 эволюции)
- Визуальный feedback (вспышки, частицы, тряска)

### 2.2 Классы с уникальной идентичностью
- 7 архетипов со своими пассивками и Q-способностями
- Сильная славянская тематика (Воронник, Огневик, Грозник и т.д.)
- Разные стартовые оружия

### 2.3 Эволюции + Сундуки
- Классическая система эволюций через сундуки
- Рецепты эволюций с телеграфом
- Журнал находок

### 2.4 Атмосфера и мир
- Славянский лес (лучше, чем абстрактный фон VS)
- Аномалии, пропсы, живописные арты
- Процедурная музыка + слои звука

---

## 3. Что нужно улучшить, чтобы «походить на Vampire Survivors»

### 3.1 Juice и визуальный feedback (самое важное)

**Vampire Survivors** выигрывает за счёт:
- Мощных вспышек при эволюции
- Ярких следов оружия
- Визуального "взрыва" при смерти элит
- Чёткого ощущения прогресса силы

**Что нужно добавить в Чёрнолесье**:

| Фича                        | Где реализовать              | Приоритет |
|----------------------------|------------------------------|---------|
| **Крупные титры эволюций** | `ui/juice.js` + `fx-layer`   | Высокий |
| **Более яркие следы оружия** | `fx-layer.js`              | Высокий |
| **Эффект "взрыва" при смерти босса** | `fx-layer.js`         | Высокий |
| **Камера-пульс при мощных атаках** | `slowmoHit()` уже есть    | Средний |
| **Больше частиц при подборе** | `gemPops` + `pickups.js`   | Средний |
| **Экранные вспышки при синергии** | Уже частично есть         | Доработать |

### 3.2 Полировка интерфейса

**Текущие проблемы**:
- Экран выбора карт выглядит "тяжёлым"
- Мало анимаций при взятии карты
- Слабый feedback при открытии сундука

**Нужно**:
- Анимация появления карт (как в VS)
- Более яркие рамки редкости
- Звуки при взятии карты / эволюции

### 3.3 Мобильная полировка

**Что уже хорошо**:
- Джойстик и тач-управление
- Адаптивный HUD

**Что нужно улучшить**:
- Более крупные кнопки спецатак
- Лучшая видимость следов оружия на маленьком экране
- Оптимизация частиц под слабые устройства (уже есть `partMul`)

### 3.4 Аудио-juice

**Vampire Survivors** имеет очень сильный sound design.

**Что можно добавить**:
- Более разнообразные звуки ударов по разным типам врагов
- Звуки при получении редкой карты
- Более мощный звук при эволюции и синергии
