# Задания на арт эффектов

Кодом уровень Vampire Survivors не берётся: кольцо остаётся кольцом. Там у
каждого оружия свой **силуэт**, нарисованный непрозрачно поверх тёмного фона.
Ниже — что генерировать, чтобы это получить, и как оно попадает в игру.

---

## Технические требования — одинаковые для всех листов

| | |
|---|---|
| Размер холста | 1280×640 или 1254×1254 — не важно, режется по сетке |
| Сетка | **строго 4 столбца × 2 строки**, 8 кадров, ячейка квадратная |
| Порядок кадров | слева направо, сверху вниз: рождение → пик → затухание |
| Фон | **сплошной magenta `#FF00FF`**, без градиента и виньетки |
| Заполнение кадра | эффект **от края до края** ячейки и по центру |
| Прозрачность | не нужна, её сделает инструмент |

Последний пункт критичен. Лист рисуется диаметром `2R`, где `R` — настоящий
радиус попадания. Если эффект занимает середину кадра с большими полями, на
экране он окажется вдвое меньше зоны, и игрок снова не увидит, куда бьёт.

Виньетка на фоне — вторая частая беда. Прошлый лист взмаха меча пришёл с
затемнением по углам (центр `249,1,248`, углы `72,4,76`), порог по «похоже на
`#FF00FF`» снял только центр, и вокруг каждого кадра остался розовый ореол.
Проси **ровный фон**.

## Как ассет попадает в игру

```bash
# 1. Оригинал на magenta кладём в исходники
cp ~/скачано/kosa-src.png assets/art/_chromakey-src/kosa-zone-src.png

# 2. Снимаем хромакей и режем в общий формат 640x320
python3 tools/chromakey.py assets/art/_chromakey-src/kosa-zone-src.png \
        assets/art/art-registry/kosa-zone-sheet.webp --grid 4x2

# 3. Вписываем в манифест (иначе сборка не найдёт ассет)
#    src/build.manifest.json -> "art/art-registry/kosa-zone-sheet.webp": "image/webp"

# 4. Регистрируем в реестре зон — одна строка в src/game/data/weapon-fx.js:
#    WFX_SHEETS.kosa = (function(){const i=new Image();
#      i.src='@@A:art/art-registry/kosa-zone-sheet.webp@@';return i;})();

npm run check && npm run build
```

Пока листа нет, зона рисуется цветным кольцом из `zoneStamp` — игра не ломается,
ассеты можно заводить по одному и смотреть результат сразу.

## Что генерировать, по приоритету

Приоритет — по тому, насколько зона велика и насколько плохо она сейчас видна.
Цвет в задании должен совпадать с `WFX` из `src/game/data/weapon-fx.js`, иначе
кольцо и лист будут спорить между собой.

### 1. Коса Моры — `kosa`, зона 494px (165% ширины кадра)

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Широкий полукруглый
> взмах косы, раскрывающийся веером на 150 градусов. Дуга занимает весь кадр от
> края до края, центр дуги — в середине ячейки. Цвет: холодная мятная зелень
> `#8affc4` с белым раскалённым ядром по внутренней кромке лезвия и тёмной
> зелёной обводкой `#0e3a28` по внешнему краю. Кадры 1-3 — дуга нарастает и
> раскрывается, 4-5 — пик, лезвие в полную ширину с ледяной крошкой, 6-8 —
> распад на морозные искры. Славянская мифология, коса Мораны, ощущение жатвы.
> Никакого текста и рамок.

### 2. Зерцало правды — `zercalo`, зона 496px

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Расходящаяся
> кольцевая волна отражённого света, как круг по воде из зеркала. Волна
> заполняет кадр целиком к 4-му кадру. Цвет: ледяное серебро `#d8f0ff`,
> белое ядро, тёмно-серая обводка `#2a3c48`. В волне угадываются осколки
> зеркала и слабый двойник силуэта. Кадры 1-2 — вспышка в центре, 3-5 —
> кольцо расходится к краям, 6-8 — гаснет, осколки тают.

### 3. Вихрь Стрибога — `vihr`, зона 423px

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Воронка ветра
> сверху вниз, спираль из полос воздуха и сорванных листьев, закрученная
> против часовой. Занимает весь кадр. Цвет: бледная небесная синь `#a8e8ff`,
> белые скоростные линии, тёмно-синяя обводка `#0e3a52`. Кадры 1-3 — воронка
> раскручивается от центра, 4-6 — полная спираль, 7-8 — рассыпается.

### 4. Колокол Яви — `kolokol`, зона 192px

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Звуковая волна
> от удара колокола: концентрические кольца сжатого воздуха с рябью, в
> кольцах угадывается славянский орнамент. Заполняет кадр. Цвет: тёплое
> золото `#ffc247`, белое ядро в центре, тёмно-коричневая обводка `#5a3a08`.
> Кадры 1-2 — удар, вспышка в центре, 3-6 — кольца расходятся, 7-8 — затухают.

### 5. Клюка Яги — `klyuka`, зона 330px

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Удар посохом в
> землю: расходящаяся ударная волна с трещинами по земле и всполохами костяной
> пыли. Заполняет кадр. Цвет: тревожный красный `#ff6a6a`, белое ядро в точке
> удара, тёмно-бордовая обводка `#4a0e0e`. Кадры 1-2 — момент удара, 3-5 —
> трещины расходятся, 6-8 — пыль оседает.

### 6. Навий хвост — `navi`, зона 336px

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Шлейф тени за
> спиной: рваное полотно тёмного дыма с проступающими костлявыми пальцами,
> раскрывается конусом назад. Заполняет кадр. Цвет: густой фиолетовый
> `#7a5cff`, бледно-сиреневые прожилки, почти чёрная обводка `#180f3c`.
> Кадры 1-3 — тень тянется, 4-5 — пик, 6-8 — втягивается обратно.

### 7. Венец костей — `kosti`, зона 269px

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Костяные лучи,
> расходящиеся из центра короной на 360 градусов. Заполняет кадр. Цвет:
> тёплая кость `#ffe0b0`, белые кончики лучей, тёмно-коричневая обводка
> `#503418`. Кадры 1-3 — лучи выстреливают наружу, 4-5 — полная корона,
> 6-8 — рассыпаются в костяную крошку.

### 8. Зерно Марены — `zerno`, зона 224px

> Спрайт-лист 4×2, 8 кадров, фон сплошной magenta #FF00FF. Взрыв побегов из
> земли: рваный круг из прорастающих чёрных стеблей с ядовитыми соцветиями.
> Заполняет кадр. Цвет: болотная зелень `#9ac06a`, белое ядро вспышки,
> тёмно-зелёная обводка `#22380f`. Кадры 1-2 — земля вспучивается, 3-5 —
> побеги выстреливают, 6-8 — опадают.

## Проверка готового листа

```bash
python3 tools/chromakey.py вход.png /tmp/проверка.webp --grid 4x2
```

Инструмент печатает рамку содержимого. Если она заметно меньше ячейки —
эффект в кадре с полями, и на экране он будет мельче зоны поражения: проси
перегенерировать «от края до края».

Дальше открыть результат на тёмном фоне и посмотреть, нет ли розовых остатков
по краям. Если есть — фон был с виньеткой, см. требования выше.
