# Тестовая папка

Эта папка создана для тестирования процесса публикации и проверки работы Git.

## Назначение
- Проверка возможности создания изменений в репозитории
- Тестирование процесса коммита и пуша
- Временное хранение тестовых файлов

## Примечание
Файлы в этой папке могут быть удалены после завершения тестирования.
